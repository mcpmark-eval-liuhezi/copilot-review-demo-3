# copilot-review-demo-3

Live demo repository for a team show-and-tell on **GitHub Copilot code review**.

## What this repo is for

This is a throwaway sandbox used to walk the team through Copilot code review on a real
pull request instead of static screenshots:

1. A branch, `demo-tweak`, adds a single small file of demo notes.
2. A pull request, **"Add demo notes"**, is opened from `demo-tweak` into `main`.
3. A GitHub Copilot code review is requested on that pull request so everyone can watch
   the review arrive and read the comments together.

## What to watch for in the demo

- Requesting a review: on the pull request, under **Reviewers** in the right sidebar,
  next to Copilot, click **Request**.
- Copilot's review usually comes back in **under 30 seconds**.
- Comments are labelled with a severity of **High / Medium / Low**.
- By default Copilot leaves a **Comment** review, not an "Approve" or "Request changes"
  review, so it does not count toward required approvals.
- Where possible, feedback includes suggested changes you can apply with a couple of clicks.

See the official documentation:
[Using GitHub Copilot code review](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/request-a-code-review/use-code-review)
